## 🎮 About the Game

**Lemonoids** is a fun, lemon-themed spin on the classic 1979 arcade hit *Asteroids*. 

Pilot your trusty ship through deep space as you dodge, shoot, and blast incoming giant space lemons (Lemonoids) into smaller citrus slices! Manage your thrust, aim carefully, and survive as long as possible to set a high score.

### ✨ Key Features
* 🚀 **Physics-Based Movement:** Smooth rotation and momentum-based ship thrust.
* 🍋 **Splitting Targets:** Large lemonoids split into smaller, faster lemon slices when hit.
* 💯 **Score Tracking:** Track your high score across runs.
* 🎵 **Retro Sound Effects:** Custom retro arcade sound effects and animations.

## 🕹️ Controls

| Action | Key / Control |
| :--- | :--- |
| **Rotate Ship Left** | `A` or `Left Arrow` |
| **Rotate Ship Right** | `D` or `Right Arrow` |
| **Thrust Forward** | `W` or `Up Arrow` |
| **Shoot Laser** | `Spacebar` |
| **Restart Game** | Click **Green Flag** 🟢 |

### Play / Edit Locally
1. Download the `.sb3` project file from this repository ([`Lemonoids.sb3`](./Lemonoids.sb3)).
2. Open the [Scratch 3.0 Offline Editor](https://scratch.mit.edu/download) or visit [scratch.mit.edu](https://scratch.mit.edu/projects/editor/).
3. Click **File** > **Load from your computer** and select the `.sb3` file.
